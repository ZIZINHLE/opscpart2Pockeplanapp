Pocket Plan

Pocket Plan is a modern Android budgeting application designed for students and young adults to manage their personal finances in a simple and user-friendly way.

The application allows users to:

Track income and expenses
Set savings goals
Upload receipt images
Monitor spending habits
View financial summaries and spending analysis
